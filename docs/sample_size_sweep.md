# Records request sample size: what changes

How many charts a plan requests per flagged provider (the response model is the same as the main runs: 80% respond, late ones are discarded). Upcoders: 8 per dataset. Generated by `python eval/sample_size_sweep.py`; the rules sweep is built by `eval/make_v2_sample_sweep.py` and the AI runs by `eval/make_v2_ai_runs.py`.
