## Order
1. In parallel, as soon as this page is merged: the sealed data 4.3 build; the score 4.3 sourcing research; the agent gate (#208) and the evaluation modes (#207), which need neither.
2. When the data 4.3 pull request is merged: build the development seeds, re-measure the spread on the first 20, update the oracle and the scorer for its truth schema, stress-test the oracle.
3. When the score proposal is signed off by Simmy: re-score the references (workflow v4.0 to v4.2 and agent v5.0 to v5.2 from stored runs, workflow v4.2 re-run on data 4.3) and publish that table first.
4. The loop on W4.3 (free), then the freeze declaration, the confirm read and the final development run, the agent build (A5.3 mirrors W4.3, plus the gate), parity, the paid test, close-out.
Blockers are written into the pin list in the task list and in the decision log; independent work goes on while they clear.

## Yardsticks for the release's test
- **Workflow v4.2 re-run on the new test seeds** (free); a same-list or same-cap control for any mechanical gain.
- **Zero** (do nothing).
- **The oracle under score 4.3 and data 4.3**, built and stress-tested in step 2, reported as score over oracle in every table.
- The previous agent (A5.2) is not re-run; the new agents are compared with W4.2 and W4.3 on the same seeds. A5.3-O (Opus) and A5.3-S (Sonnet) are declared together in the freeze declaration.

## Seed plan (to be recorded in the registry when data 4.3 exists)
Pools keyed by data version 4.3: development 100 seeds (1003 + 41j, role select), confirm 100 (1004 + 41j, read once per declared decision), test 10 (6003 + 41j, never generated before the freeze), reserved 10 (7003 + 41j). Data 4.2 pools are used up except D4.2-RESERVED (5100 + 37j, untouched, kept). Seeds are generated by the public build command; the test and reserved pools are not built until the freeze.

## Power plan
v4.2's gain ($35,000 per seed, spread $21,000) says nothing about the size of effects to expect now: the model comparison, a robust lane and level reach are expected to move scores by hundreds to thousands of dollars per seed. The spread of paired per-seed differences is re-measured on the first 20 data 4.3 seeds (W4.2 against W4.2 variants and against zero) before the pools' use is fixed; the plan assumes 100 seeds detect about $300 per seed at the 0.05 level if the spread is near $1,000.

## Paid steps and the cap
Only the agent runs on the model API key: **A5.3-O about $1.8** and **A5.3-S about $0.9** on the ten test seeds, one run each, $1 per run, total about $2.7 against `paid cap=4`. No run-to-run variance runs. Sourcing, research and the data build use in-session sub-agents and tools, not the key, and are outside the cap.

## Ask first in this release
The score 4.3 values (referral cost, collection, appeals, copy fee, error gate): the run writes `docs/score_43_proposal.md` and asks one question. The scope of data 4.3 was decided on 2026-10-25 (issue 197) and is not reopened.
