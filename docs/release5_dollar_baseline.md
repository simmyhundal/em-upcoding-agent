# Release 5 baseline: every arm in dollars (the primary score), issue 109

[Back to the README](../README.md)

Generated by `python eval/release5_dollars.py`. Free. **Net dollars = the 90% lower bound of the overpayment each arm could extrapolate from its own random charts on the upcoders it calls, minus its costs** ($90 per round for copied records, $43.84 per round to an honest practice, $158 per practice reviewed, $2,000 per honest doctor called: sources and caveats in `eval/dollar_reward.py`; the last is an assumption). Release 5 develops on this score; the release 4 points score is not the development direction and can be back-scored later. **Caveats:** the dollars are a ranking at the simulated scale (providers have about 240 claims a year); cloned-notes upcoders are worth about nothing here until the recovery model of issue 109 exists; L and GL are cross-validated on the release 2 and 3 seeds and out of sample on the release 4 seeds.

## Reading

- Compare arms within a table only; seeds and data differ between tables.
- An arm below $0 loses money against asking nobody at these prices and this scale; the dollar score rewards asking only where the documented recovery pays for the asking.
- Break-even scale: how many times larger the values would have to be (a bigger real practice, a longer look-back) for the arm to break even.
