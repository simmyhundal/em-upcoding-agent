scores from different versions are not strictly comparable (see the re-judging issue). **Evals passed (of 5)**: passes scaled to a common five-point score (5 x passed / scored) so rows with different numbers of applicable evals read on one scale; it is still not a like-for-like comparison, because different evals apply. **Evals scored**: how many of the evals applied to that row (a screen row has 3; an AI row has 4, or 5 when the usefulness judge ran), so compare passes only between rows with the same count; the templating check was removed, which lowered AI rows' count by one. **Agents**: separate model calls or chat agents that wrote summaries (code-written ones do not count). **Upcoders in data**: the share of providers that are real upcoders (the prevalence; "baseline" is used only for a comparison arm). **Honest doctors sent records requests** and **Request rounds**: the burden on practices (a round is the first request or one follow-up). **Dollars overpaid to upcoders**: what upcoders were paid above what the justified levels would have paid (answer key). **Dollars at stake in upcoders called**: the same dollars for only the upcoders that stage called, an upper bound on what recovery could reach. **Upcoder clone level**: the share of upcoders whose notes are cloned to match the bill.
