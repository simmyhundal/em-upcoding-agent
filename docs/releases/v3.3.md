# v3.3

The agent mirroring workflow v2.3, on data 2.2. Evaluated once on ten fresh seeds with a pre-registered rule (issue 99).

![The flow this version builds on](https://raw.githubusercontent.com/simmyhundal/em-upcoding-agent/main/docs/images/how_it_works_v3.0.svg)

## What changed
1. **Rules 2.3 in `hybrid_review` and the lint**, the `eb_ratio_t` screen, a prompt that explains cloned notes and the chart test, records budget 22.
2. Same $1 cap and Opus 5.5 low effort (about $0.23 a seed).

## Headline result
Ten fresh seeds (2525 to 3434): **34 of 79 upcoders found (43% recall), 1 honest accused (97% precision)**, 79 honest practices asked for charts. Workflow v2.3 against agent v3.3: 12 upcoders found only by the workflow, 9 only by the agent; p = 0.59, **no significant gap**.

Full tables: [docs/release3_results.md](https://github.com/simmyhundal/em-upcoding-agent/blob/v3.3/docs/release3_results.md) and [docs/eval61.md](https://github.com/simmyhundal/em-upcoding-agent/blob/v3.3/docs/eval61.md).

## Known limits
- Found nearly as many upcoders as v2.3 with about half the honest requests; its reading of charts matches the rules, so the gap is in which providers it asks.
- Ten seeds, one data version, generated notes, low effort.
