# v2.1

The workflow on data 2.1: charts now arrive with the note package (note text, signatures, orders and results, an audit trail), and the workflow checks the claim against the note. Evaluated with the agent on ten fresh seeds (#61); the workflow stays the main line.

![The v2.0 flow, which v2.1 keeps: statistics screen, code asks for charts and settles the clear cases, AI handles the rest. Humans review.](https://raw.githubusercontent.com/simmyhundal/em-upcoding-agent/main/docs/images/how_it_works_v2.0.svg)

## What changed from v2.0
1. **Data 2.1.** The same claims and records as data 2.0, plus the note package a records request returns ([data_v2_1.md](https://github.com/simmyhundal/em-upcoding-agent/blob/v2.1/docs/data_v2_1.md)).
2. **Provider office 2.1.** A second, targeted records request after the first random one; up to 5 rounds; an audit-trail request the office may refuse.
3. **Note rule.** Code compares the bill with the note (cloned text, time and signature signals) and the fixed v2.1 policy decides when to follow up.
4. **Summaries.** Next steps depend on the findings, and a shared lint repairs or rejects summaries that contradict the evidence or quote numbers that do not match.

## Headline result
Ten fresh seeds (80 planted upcoders): **32 of 80 upcoders found, 0 honest doctors accused** (v2.0 on the same seeds: 19 of 80, 3 accused). Paired by seed, v2.1 finds 1.3 more upcoders per seed than v2.0 (95% interval +0.6 to +2.0). Cloned-notes upcoders found rose from 3 to 10 of 40.

Full tables: [docs/eval61.md](https://github.com/simmyhundal/em-upcoding-agent/blob/v2.1/docs/eval61.md).

## Known limits
- Still misses 60% of upcoders; no arm meets the 12.5% miss-rate threshold.
- More burden: 203 request rounds to honest practices against 80 for v2.0 (#87).
- Most overpayment estimates rest on fewer than 8 reviewed 99215 charts (#86).
- The clone signals are planted by the generator, so real notes would be harder.
- Synthetic data from one generator family; honest doctors bill exactly the justified level (#74).
