# v3.4

The agent with a read-only advisor tool and an enforced rule check, on data 2.2. Evaluated once on the release 4 fresh seeds (issue 108).

![The flow this version builds on](https://raw.githubusercontent.com/simmyhundal/em-upcoding-agent/main/docs/images/agent.svg)

## What changed
1. **Advisor tool `advise_next_step`.** Says ask or skip before a request and, after the first sample, what the workflow's learned rule would do next. Advice only.
2. **Rules enforced.** `submit_findings` refuses until `hybrid_review` has run on every provider whose records arrived.

## Headline result
Ten fresh seeds (3535 to 4444): **40 of 80 upcoders found (50% recall), 3 honest accused (93% precision), $26,505 net per seed**. Against workflow v2.4 (49 of 80 found), it found fewer upcoders and sent far fewer rounds to honest providers (108 against 282). **It never called the advisor tool** in ten runs (docs/release4_agent_results.md, docs/release4_misses.md).

Full tables: [docs/release4_results.md](https://github.com/simmyhundal/em-upcoding-agent/blob/v3.4/docs/release4_results.md) and [docs/release5_dollar_baseline.md](https://github.com/simmyhundal/em-upcoding-agent/blob/v3.4/docs/release5_dollar_baseline.md).

## Known limits
- The advice was not used, so v3.4 does not test whether the learned rule helps an agent.
- Agent cost about $0.25 a run (Opus 5.5, low effort); ten seeds.
