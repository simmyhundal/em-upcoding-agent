# v3.2

The agent on harder data (data 2.2), with the data-quality tools and the new screens. Evaluated with workflow v2.2 on ten seeds.

![The flow this version builds on](https://raw.githubusercontent.com/simmyhundal/em-upcoding-agent/main/docs/images/how_it_works_v3.0.svg)

## What changed
1. **Data-quality tools** `data_quality` and `flag_data_issue`; findings affected by a data problem need chart evidence.
2. **Screens** `eb_ratio` and `priority` with a percentile cutoff (`top_pct`).
3. **Cost controls.** $1 cap per run, Opus 5.5 at low effort (about $0.19 a seed), no LLM judge.

## Headline result
Ten seeds (1515 to 2424): **12 of 78 upcoders found (15% recall), 1 honest accused (92% precision)**, 58 honest practices asked for charts. Not significantly different from workflow v2.2 by the pre-registered plan (the ten-seed look was unplanned; see v2.2).

Full tables: [docs/release2_results.md](https://github.com/simmyhundal/em-upcoding-agent/blob/v3.2/docs/release2_results.md) and [docs/eval61.md](https://github.com/simmyhundal/em-upcoding-agent/blob/v3.2/docs/eval61.md).

## Known limits
- Found fewer upcoders than the workflow on these seeds.
- Low effort and one model; a different setting might behave differently.
- Same data limits as v2.2.
