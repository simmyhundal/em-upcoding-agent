## Reading

- This is the simplest reinforcement-learning form (a one-step contextual bandit with a reward we can compute for both actions), chosen because the ask or skip decision has no hidden state beyond the screen features. It does not yet learn the follow-up and escalation decisions (Stage 2).
- A learned policy that only matches the hand-set gate is still a result: it shows the gate is about as good as these features allow. One that beats it at matched burden is a hypothesis for the fresh test, not a finding.
- Cross-validation here is by seed within development data that the hand-set gates were also chosen on; the fresh 10-seed test is the only unbiased comparison.
