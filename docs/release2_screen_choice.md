Generated by `python eval/release2_screen_choice.py --write`. Free: claims only; the answer key only scores. The first batch of the release 2 evaluation ([#90](https://github.com/simmyhundal/em-upcoding-agent/issues/90)): seeds 1515, 1616, 1717, 1818, 1919, 2020, 2121, 2222, each 216 doctors, 8 planted upcoders, 8 high-acuity doctors, half the upcoders cloning notes, data 2.2 defaults, payer-based upcoder definition.
